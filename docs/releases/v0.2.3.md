# Marufia Online Alpha 0.2.3

Esta é uma versão de **pré-lançamento** do Marufia Online preparada para a tag
`v0.2.3`.

## Correção do servidor de campanhas

- fixa `https://api.marufiarpg.org` como o backend oficial de produção;
- impede que builds do site ou do aplicativo Windows apontem para o Supabase Cloud legado;
- registra o backend dentro do relatório dos executáveis e reprova a release se houver divergência;
- preserva campanhas, participantes, personagens, rolagens, permissões e o schema v5.

Depois da atualização, quem ainda usava uma versão conectada ao ambiente antigo
deve entrar novamente na conta para carregar as campanhas do servidor oficial.

## Arquivos para Windows x64

- `Marufia.exe` — versão portátil, sem instalação;
- `Marufia-Setup.exe` — instalador para o usuário atual.

O Windows pode exibir um alerta do SmartScreen porque este Alpha está **sem assinatura digital**. Não desative as proteções do sistema: confirme o nome do arquivo e compare o SHA-256 antes de executar.

## Publicação segura

A tag, a pré-release e o manifesto público permanecem sem publicação até autorização explícita. Primeiro serão publicados os executáveis; somente depois o site anunciará a versão `0.2.3`.
