# Marufia Online Alpha 0.1.0

Esta é a primeira versão de pré-lançamento do Marufia Online. A tag correspondente é `v0.1.0`.

## Destaques

- ficha original preservada, com schema v5 e salvamento local prioritário;
- conta, campanhas, personagens e sincronização online com proteção contra conflitos;
- painel do Mæstre com operações granulares autorizadas;
- rolagens públicas, secretas e privativas do Mæstre com visibilidade controlada no servidor;
- aplicativo Windows portátil e instalador em português do Brasil;
- interface responsiva validada em desktop e celular.

## Arquivos para Windows x64

- `Marufia.exe` — versão portátil, sem instalação;
- `Marufia-Setup.exe` — instalador para o usuário atual.

O Windows pode exibir um alerta do SmartScreen porque este Alpha está **sem assinatura digital**. Não desative as proteções do sistema: confirme o nome do arquivo e compare o SHA-256 antes de executar.

## Validação

- 11 testes Python aprovados;
- 306 testes JavaScript aprovados;
- build Windows x64 concluído;
- hashes e estrutura dos executáveis verificados;
- navegação da ficha validada em desktop e celular.

## Observações do Alpha

O serviço online requer uma conta e conexão com a internet. Se a conexão falhar, os dados continuam salvos localmente e a sincronização pode ser retomada depois. Faça backup da ficha antes de substituir dados ou trocar de dispositivo.
