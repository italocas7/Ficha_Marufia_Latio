# Marufia Online Alpha 0.2.0

Esta é uma versão de **pré-lançamento** do Marufia Online. A tag correspondente será `v0.2.0` depois da autorização de publicação.

## Destaques

- aviso acessível quando uma versão mais nova do aplicativo Windows estiver disponível;
- botão de atualização limitado à página oficial da GitHub Release;
- opção **Agora não**, válida somente durante a sessão atual;
- nova tentativa silenciosa quando a conexão retornar;
- ficha original, regras de RPG, schema v5 e salvamento local preservados;
- correções de campanhas, confirmação de email, personagens e rolagens incluídas desde a versão anterior.

O aplicativo `0.1.0` ainda não possui o verificador. É necessário instalar `0.2.0` manualmente uma vez; as versões posteriores poderão apresentar o aviso dentro do aplicativo.

## Arquivos para Windows x64

- `Marufia.exe` — versão portátil, sem instalação;
- `Marufia-Setup.exe` — instalador para o usuário atual.

O Windows pode exibir um alerta do SmartScreen porque este Alpha está **sem assinatura digital**. Não desative as proteções do sistema: confirme o nome do arquivo e compare o SHA-256 antes de executar.

## Validação

- 11 testes Python e 342 testes JavaScript;
- navegador em desktop e celular;
- configuração e segurança Tauri;
- build do site e build Windows x64;
- hashes e estrutura dos executáveis.

## Publicação segura

Primeiro são anexados os dois executáveis à GitHub Release. Somente depois `app-update.json` é publicado no site, para nunca oferecer um download inexistente. Nenhuma dessas ações será executada sem autorização explícita.
