# Marufia Online Alpha 0.3.1

Esta é uma versão de **pré-lançamento** do Marufia Online preparada para a tag
`v0.3.1`.

## Abertura de fichas da conta

- transforma os personagens de **Minhas fichas** em opções selecionáveis;
- adiciona **Abrir ficha selecionada** para carregar a versão online no site ou no aplicativo;
- distingue essa ação de **Continuar na ficha atual**, que apenas fecha o painel;
- cria um backup local antes de substituir uma ficha já aberta;
- conclui salvamentos pendentes antes da troca e vincula a ficha carregada à sincronização da conta;
- mantém uma confirmação adicional quando a troca substituir outra ficha no aparelho.

## Compatibilidade

O schema da ficha permanece v5. `app.js`, `data.js`, banco de dados, formatos de
importação e exportação, probabilidades e regras de Marufia não foram alterados.

## Arquivos para Windows x64

- `Marufia.exe` — versão portátil, sem instalação;
- `Marufia-Setup.exe` — instalador para o usuário atual;
- `Marufia-Setup.exe.sig` — assinatura criptográfica obrigatória do atualizador.

O pacote possui **assinatura criptográfica do atualizador**, validada pelo Tauri antes da instalação. O Windows ainda pode mostrar um alerta porque este Alpha permanece **sem assinatura Authenticode** comercial.
