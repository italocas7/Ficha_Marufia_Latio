# Marufia Online Alpha 0.2.1

Esta é uma versão de **pré-lançamento** do Marufia Online. A tag correspondente será `v0.2.1` depois da autorização de publicação.

## Correção

- corrige o bloqueio ao abrir a ficha completa de um jogador na **Visualização do Mæstre** dentro do aplicativo Windows;
- permite somente a página interna de leitura da própria ficha, mantendo frames externos bloqueados;
- habilita os atalhos nativos `Ctrl` + `+`, `Ctrl` + `-` e `Ctrl` + `0` para controlar o zoom;
- adapta o resumo de combate à largura disponível e impede a sobreposição dos textos de PV, PM e demais cartões;
- preserva a leitura autenticada, o isolamento por campanha e o envio protegido do estado pelo token da visualização;
- mantém regras de RPG, schema v5, banco de dados e formatos de importação e exportação inalterados.

## Arquivos para Windows x64

- `Marufia.exe` — versão portátil, sem instalação;
- `Marufia-Setup.exe` — instalador para o usuário atual.

O Windows pode exibir um alerta do SmartScreen porque este Alpha está **sem assinatura digital**. Não desative as proteções do sistema: confirme o nome do arquivo e compare o SHA-256 antes de executar.

## Validação

- 11 testes Python e 344 testes JavaScript;
- configuração de segurança limitada a frames internos do próprio aplicativo;
- navegador em desktop e celular;
- build Windows x64, hashes e estrutura dos executáveis.

## Publicação segura

Primeiro serão publicados os dois executáveis e a GitHub Release. Somente depois `app-update.json` será atualizado no site, evitando anunciar um download inexistente. Nenhuma dessas ações será executada sem autorização explícita.
