# Teste real entre computadores — Fase 41

Esta fase publica a mesma ficha web validada nas fases anteriores. Não é necessário instalar programas: cada participante abre o endereço de teste no navegador e usa uma conta própria. O executável Windows será preparado somente depois, nas fases de Tauri.

## Teste simples

1. No primeiro computador, abra o endereço publicado e entre com a conta do Mæstre.
2. Crie uma campanha e copie o código de convite.
3. No segundo computador, abra o mesmo endereço e entre com outra conta.
4. Use o código para entrar como Jogador e associe um personagem à campanha.
5. Altere o PV no computador do Jogador e confirme a atualização no painel do Mæstre.
6. Altere o PV do Jogador pelo painel do Mæstre e confirme o recebimento no segundo computador.
7. Faça uma rolagem pública em cada computador e confirme que ela aparece para os participantes.
8. Faça uma rolagem secreta como Jogador e confirme que somente quem rolou e o Mæstre a recebem.
9. Recarregue as duas páginas e confirme personagens, campanha e valores.

Para um terceiro participante, repita apenas os passos de entrada, associação e rolagem em outro navegador ou computador.

## O que informar se houver problema

Anote o papel usado — Mæstre ou Jogador —, a ação realizada, o horário aproximado e o navegador. Se possível, envie uma captura da mensagem exibida. Não envie senha, código recebido por e-mail nem qualquer chave do projeto.
